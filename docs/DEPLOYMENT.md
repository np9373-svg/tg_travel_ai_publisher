# Deployment Guide

Инструкция по развертыванию проекта TG Travel AI Publisher.

Проект представляет собой автоматизированный pipeline, который:

-   извлекает новости из RSS-лент
-   проверяет релевантность рубрике с помощью AI
-   формирует summary с помощью AI
-   генерирует пост с помощью AI
-   публикует его в Telegram

Развертывание занимает примерно 5--15 минут.

------------------------------------------------------------------------

# Требования

## Доступ к внешним API

Проект использует внешние сервисы:

-   OpenAI API (или совместимый провайдер)
-   Telegram API
-   jina.ai
-   Yandex Cloud API

Если сервер находится в регионе, где доступ к этим сервисам ограничен, необходимо:

-   использовать сервер за пределами РФ или
-   настроить VPN с маршрутизацией всего трафика через него

------------------------------------------------------------------------

## Установленное ПО

На сервере должны быть установлены:

-   Docker
-   Docker Compose
-   Git

Проверка:

``` bash
docker --version
docker compose version
git --version
```

------------------------------------------------------------------------

# 1. Клонирование репозитория

Создайте директорию проекта:

``` bash
mkdir tg_travel_ai_publisher
cd tg_travel_ai_publisher
```

Клонируйте репозиторий:

``` bash
git clone https://github.com/np9373-svg/tg_travel_ai_publisher .
```

------------------------------------------------------------------------

# 2. Настройка переменных окружения

Создайте файл `.env`  на основе `.env.example`:

``` bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

``` env
OPENAI_KEY=<API ключ OpenAI или совместимого провайдера>
OPENAI_BASE_URL=<endpoint OpenAI API>
FOLDER_ID=<ID папки Yandex Cloud>
YC_API_KEY=<API ключ Yandex Cloud с правами генерации изображений>
N8N_HOST=<IP адрес сервера или localhost>
N8N_BASIC_AUTH_USER=admin
N8N_BASIC_AUTH_PASSWORD=secret
TG_CHAT_ID=<ID Telegram чата (с минусом)>
```

------------------------------------------------------------------------

# 3. Запуск сервисов

Запустите все сервисы:

``` bash
docker compose up -d
```

Проверить статус:

``` bash
docker compose ps
```

Просмотр логов:

``` bash
docker compose logs -f
```

------------------------------------------------------------------------

# 4. Открытие интерфейса n8n

Откройте браузер:

http://<N8N_HOST>:5678

Cоздайте аккаунт с почтой и паролем при первом запуске.

------------------------------------------------------------------------
# 5. Настройка Credentials
## OpenAI

Credentials → New → OpenAI API

Укажите:

API Key = OPENAI_KEY\
Base URL = OPENAI_BASE_URL

------------------------------------------------------------------------

## Telegram

Credentials → New → Telegram API

Укажите:

Bot token

------------------------------------------------------------------------


# 6. Импорт и настройка workflow

Импортируйте:

-   Extract_RSS.json
-   Check_news_relevance.json
-   Summarize_news_item.json

Шаги:

1.  Workflows → Import from file
2.  Выберите файл
3.  Назначьте open ai credentials в нодах типа OpenAi
4.  Назначьте соответствующее название воркфлоу
5.  Save

Импортируйте:
-   Main.json

Шаги:

1.  Workflows → Import from file
2.  Выберите файл
3.  Назначьте telegram credentials в нодах Send_alert_message, Send_post
4.  Настройке вызов соответствующих воркфлоу в нодах Extract_news_from_RSS, Check_news_relevance, Summarize_news_item 
5.  Назначьте соответствующее название воркфлоу
6.  Save

------------------------------------------------------------------------

# 7. Активация workflow

Откройте workflow Main и нажмите Activate.

------------------------------------------------------------------------

# 8. Запуск

Ручной Execute Workflow или по расписанию
