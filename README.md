# tg_travel_ai_publisher
## О проекте

Решение для автоматической подготовки и публикации туристического контента в Telegram-группе на основе заданных RSS-источников и AI.

Проект полностью автоматизирует pipeline от получения новости до публикации готового поста.

## Для кого

Проект предназначен для:

- авторов туристических Telegram-каналов
- travel-блогеров
- команд, автоматизирующих travel контент-pipeline

Особенно полезен при работе с несколькими RSS-источниками.

## Какую проблему решает

Источники есть, идей хватает, но чтение и публикация постоянно откладываются.
Материалы накапливаются быстрее, чем превращаются в посты.

Система автоматизирует рутинную часть процесса.
Автор остаётся в роли редактора, а не исполнителя.

## Результат

Подготовка и публикация контента перестаёт требовать постоянного участия.  
Достаточно задать RSS источники и расписание — дальше система берёт рутинную работу на себя.  


## Функциональность

- приём вручную заданных RSS-источников  
- загрузка последних материлов из RSS за сутки
- отбор материала, отвечающего рубрике (рубрики места, события и советы меняются раз в сутки)
- резюмирование материала  
- генерация постов в заданном стиле и объёме  
- генерация изображений по теме поста  
- публикация сообщений в Telegram чате раз в сутки
- публикация информационных сообщений в Telegram чате в случае наступления ошибки в процессе 

*примечание: публикация возможна по другому расписанию, но не чаще 3 раз в сутки без риска дублирования контента*

## Архитектура

Система построена как набор логически изолированных сервисов, оркестрируемых через n8n.

Основные сервисы:

- сервис извлечения данных
- сервис фильтрации по рубрике
- сервис суммаризации
- сервис генерации контента
- сервис оркестрации
