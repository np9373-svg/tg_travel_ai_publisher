# tg_travel_ai_publisher
## О проекте

Решение для автоматической подготовки и публикации туристического контента в Telegram-группе на основе заданных RSS-источников.

## Для кого

Проект предназначен для авторов Telegram-каналов, которые работают с несколькими RSS источниками и хотят поддерживать регулярные публикации без ручной подготовки каждого поста.

## Проблема

Источники есть, идей хватает, но чтение и публикация постоянно откладываются.
Материалы накапливаются быстрее, чем превращаются в посты.

## Результат

Подготовка и публикация контента перестаёт требовать постоянного участия.  
Достаточно задать источники и расписание — дальше система берёт рутинную работу на себя.  
Автор остаётся в роли редактора: контролирует результат, а не пишет каждый пост с нуля.


## Функциональность

- приём вручную заданных RSS-источников  
- загрузка последних материлов за сутки
- отбор материала, отвечающего рубрике
- резюмирование материала  
- генерация постов в заданном стиле и объёме  
- генерация изображений по теме поста  
- публикация сообщений в Telegram чате по расписанию
